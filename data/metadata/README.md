# Metadata files

`dataset_sources.csv` is a public, path-free extraction of the accepted final Supplementary Table S1 plus the frozen dataset manifests. Fields not recoverable at stable-file granularity are explicitly marked `TO VERIFY`.

`frozen_input_hashes.csv` records the SHA-256 values of the 19 prepared H5AD inputs used by the locked analysis. The data files themselves are not redistributed. Hashes identify the prepared analysis objects, not the upstream raw downloads.

# Released results

This directory contains small, non-sensitive derived data and final rendered
figures. It does **not** contain raw expression matrices, seed-level prediction
files, model checkpoints, or third-party datasets.

- `source_data/analysis/`: integrated five-method scientific tables used by
  downstream summaries.
- `source_data/figures/`: the 27 CSV files underlying Figures 1–5 and
  Supplementary Figures S1–S8.
- `source_data/tables/`: five publication-table CSV files plus the editable
  workbook prepared from those same values.
- `figures/`: final PDF and PNG renderings for independent visual comparison.
- `provenance/`: frozen protocols and final validation records.

The files are submission snapshots. Do not treat the rendered figures as
inputs to analysis.

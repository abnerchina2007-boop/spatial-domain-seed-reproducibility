# Submission output hashes

SHA-256 hashes for every released source-data and figure file are generated by
`scripts/validation/build_release_manifest.py` into
`results/provenance/RELEASE_FILE_HASHES.sha256`. The manifest is included in
the tagged release and can be verified with:

```bash
python scripts/validation/build_release_manifest.py --check
```

The independent upstream numerical reconciliation record is retained as
`results/provenance/FINAL_FIVE_METHOD_NUMERICAL_RECONCILIATION.md`.
